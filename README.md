# CCNA Study Labs

Notes from my CCNA 200-301 studies (Wendell Odom's Official Cert Guide, Volume 1), organized by the book's own Parts and written in my own words as I work through the material.

**Background:** CompTIA A+, Network+, and Security+ (earned). Managed Services Specialist, mathematics degree.

For the full picture of my background and other projects, see my [profile README](https://github.com/elyasali-it).

## Contents

- **[Part I: Introduction to Networking](./Part1-Introduction-to-Networking)** — TCP/IP fundamentals, Ethernet basics, WANs and IP routing concepts
- **[Part II: Implementing Ethernet LANs](./Part2-Implementing-Ethernet-LANs)** — CLI operations, switch configuration, interface analysis
- **[Part III: Implementing VLANs and STP](./Part3-Implementing-VLANs-and-STP)** — VLANs, trunking, Spanning Tree, EtherChannel
- **[Part IV: IPv4 Addressing](./Part4-IPv4-Addressing)** — subnetting theory, classful networks, subnet mask analysis
- **[Part V: IPv4 Routing](./Part5-IPv4-Routing)** — router operation, static routes, VLAN routing (ROAS/SVI/routed ports), troubleshooting
- **[Part VI: OSPF](./Part6-OSPF)** — OSPF concepts, single-area implementation, neighbor relationships and route selection
- **[Part VII: IP Version 6](./Part7-IP-Version-6)** — IPv6 fundamentals, addressing/subnetting, router and host implementation, IPv6 routing

Each Part folder has a `README.md`, and where the material includes real device configs worth pulling out on their own, a `configs.md` alongside it.
