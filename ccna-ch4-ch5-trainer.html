Spanning Tree Protocol (STP)
Without STP
⟳ LOOP
SW1 ↔ SW2 broadcast storm
Network crashes
With STP
✓ SAFE
One path blocked
Loop prevented
STP runs automatically on Cisco switches. It elects a Root Bridge and blocks redundant paths to prevent broadcast storms.
